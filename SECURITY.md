# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Shoutkit, please report it through [GitHub's private vulnerability reporting](https://github.com/cascadiacollections/shoutkit-android/security/advisories/new).

Do **not** open a public issue for security vulnerabilities.

## Supported Versions

Only the latest release is supported with security updates, on each channel: Google Play, F-Droid, and [GitHub Releases](https://github.com/cascadiacollections/shoutkit-android/releases).
