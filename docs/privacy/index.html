Privacy,
in plain sight.

Updated October 11, 2026. This page describes the FOSS build of Shoutkit, developed by Cascadia Collections. Other build flavors can include different services.

What stays on your device

Your preferences, saved stations, and recent listening are stored locally. Shoutkit does not require an account. The FOSS build excludes Firebase Analytics, Crashlytics, Google Cast, and the Google Wearable Data Layer.

What connects to the internet

Station discovery uses the community Radio Browser directory and its mirrors. Audio streams connect to broadcasters' servers. Station images are fetched from their image hosts. These services receive connection information such as your IP address and standard request headers.

When optional album artwork lookup is enabled, the current artist and track title are sent to Apple's iTunes Search service to find cover art. The app's settings explain this option.

Permissions and playback

Network access supports directory browsing and audio streaming. Foreground media playback and wake locks keep audio running in the background. Notification permission shows playback controls. Network state helps the app handle connection changes and metered networks; Bluetooth permission supports headset reconnection behavior where available.

External services

Directory providers, broadcasters, and artwork hosts operate independently and may have their own logging and privacy practices. The absence of app analytics does not prevent those services from seeing network requests.

Questions and changes

Review the source code or open an issue on the project tracker. This page will be updated when the FOSS build's behavior changes.
